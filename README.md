## ✦ О проекте

**LumetaTrack** — это легкое нативное приложение для Windows, которое помогает держать баланс между работой и отдыхом за компьютером без душных отчетов и давления. 

Приложение работает в виде компактного плавающего острова, автоматически определяет активные окна и раскладывает твой день по 4 концентрическим неоновым кольцам активности:
- 🔵 **Работа** — редакторы кода, офисные программы, графические пакеты.
- 🔴 **Игры** — полноэкранные игры, клиенты Steam, Epic Games.
- 🟡 **Сёрфинг** — браузеры, чтение статей, поиск информации.
- 🟢 **Связь** — Discord, Telegram, корпоративные мессенджеры.

Ровно в **00:00** кольца плавно сбрасываются, сохраняя итоги в историю.

## ✦ 100% Приватность (Local-First)

- 🔒 **Никаких облаков и серверов:** вся история окон и времени хранится только на твоем ПК в локальной базе SQLite.
- 🚫 **Без телеметрии:** приложение не отправляет аналитику, клики, заголовки окон или скриншоты.
- 🆓 **Без аккаунтов:** не нужно логиниться, вводить почту или привязывать карту.

## ✦ Установка

### Прямой запуск:
1. Перейди во вкладку **[Releases](https://github.com/ВАШ_АККАУНТ/LumetaTrack/releases/latest)**.
2. Скачай готовый файл `LumetaTrack-Setup.exe` (или портативную версию).
3. Запусти приложение. Оно мгновенно готово к работе и появится в правом нижнем углу экрана.

### Системные требования:
* **ОС:** Windows 10 / 11 (64-bit)
* **Оперативная память:** ~35 МБ
* **Место на диске:** ~25 МБ
* **Компоненты:** Microsoft Edge WebView2 Runtime (встроен в Windows 10/11 по умолчанию)
